## 北极星

> 对话机的端态不是更聪明的编排器，而是一条可信的**任务生命周期流水线**：
> 协商（消息池）→ 单主执行（隔离 worktree 里的真实 agent 会话）→ 机器审计 + 对端评审 → 人类合并。
> 一切编排器都是这条流水线的可替换前端。

**北极星指标只有一个：被流水线合并的真实改进数。**
每周看一次；连续两周不涨，就停下脚手架回去跑任务（元工具最大的风险是"造机器永远比用机器有意思"）。

## 核心裁决

1. **三个编排器都不当主干**（driver / coordinator-v2 / collab-loop 收敛归档）。
   保留的资产：cov2 的 `evaluateVerdict` + 13 项硬审计（抽成独立 audit.mjs 纯函数）、
   driver 的 CLI 调用细节与三道停止闸、collab-loop 的"末行 COLLAB_STATUS 锚定"经验。
   理由：编排循环是便宜的可抛弃品，协议和裁判才是资产；严格 A/B 交替是对话的形状，
   不是工作的形状（"走神"问题即其症状）。
2. **真执行器不用造**：两个 CLI 本身就是带全套工具的执行器，此前是 prompt 禁止它们干活。
   缺的只是：允许干活的轮次契约 + worktree 隔离 + audit 门 + 任务状态落盘。
3. **协调基础够用作通信层、不够作进度层**：池/social-mutex/拉模式原样保留；
   补"每任务状态文件"实现 persistence over presence——任何 agent 任何时候醒来都能独立推进，
   流水线上没有任何一步要求双方同时在场。不引入常驻调度进程。
4. **协同价值的真实位置**：设计辩论（共创）、交叉评审（互检）、回顾改进（共同改造工具）。
   实现阶段单主负责（owner/reviewer 拓扑），不搞共同编辑。

## 架构四层

1. **数据层**：消息池（现有）+ 每任务状态 JSON（原子写）+ 隔离 worktree + metrics.jsonl。
2. **轮次层**：turn-wrapper——搭 prompt、起 headless CLI、解析结构化输出，
   由确定性代码落状态、发池消息、触发下一棒。**LLM 永远不直接写系统状态。**
   两种轮次契约：
   - 说话轮（辩论/评审）：只产出一条 `{type, content, refs}`，秒级结束；
   - 干活轮（executing）：owner 在 worktree 内全工具权限实现，产出 patch manifest。
3. **驱动层**：接力链（每轮末调一次 dispatch）+ 低频救援心跳（计划任务 20-30 分钟）
   + watchdog 超时释放并重派。
   原则：**贵的智能只用来干活，"要不要动"由免 LLM 的哑脚本决定**。
   "拉模式不轮询"不变量重述为：LLM 轮次绝不为"看看有没有事"而启动；哑脚本低频轮询不违反。
4. **裁判层**：audit.mjs（机器，验过程诚实）→ 对端评审（LLM，验质量）→ 人类合并（验价值）。
   三道闸各管一层，互不替代。

## 任务生命周期

```
backlog → 设计辩论(2-4轮) → 契约定稿 → claimed → executing → submitted(audit)
        → reviewing → verified → merged(人)
失败路径：audit 不过回炉 ≤3 次；评审打回 ≥2 次 → needs-human；
          超时/超预算 → released（另一 agent 可接手）
```

- 契约必须含可证伪 acceptance（验收测试），无 acceptance 不得进 executing。
- 任务粒度 ≤3 个干活轮；过大任务的第一个子任务是"拆它"。
- roadmap.json 管 what 和优先级；任务状态文件管 how 和进行时态；id 互链，互不复制字段。
- 协议变更只对合并后新建的任务生效（任务文件带 protocol_version），在飞任务用旧版跑完。

## 设计辩论协议（防互捧）

1. 主笔轮换：每任务一方出设计稿（方案/改动面/验收测试草案/风险）。
2. 批评轮格式硬约束：≥2 条带 refs 的具体风险，或走完检查单后明确"无阻塞异议"；
   笼统赞同被 wrapper 当格式错误拒收重试。
3. 修订轮逐条标注采纳/拒绝及理由（复用 cov2 的 influence record）。
4. 3-4 轮不收敛 → 第三模型仲裁 → 仍僵 → needs-human。
5. 首轮全盘同意 → 强制触发一次红队轮（过快共识是可疑信号）。

## 第三模型（GLM / 智谱）

定位 = **不下场的裁判**，不是第三个池公民（裁判与玩家训练来源不同，消解 LLM 自我偏好）：
辩论仲裁 / 双实现盲裁判（硬任务两边各做一版，GLM 只看 diff 不看作者）/ 协议红队。
接入 = ~~headless `claude -p` + ANTHROPIC_BASE_URL~~ **已作废**（2026-06-13 裁决：claude -p 全线禁用，
改为纯 HTTP API 调用智谱端点）；无状态，结论以 refs 落池。
跑顺且确实需要第三个全职辩手时再考虑升格为池公民。

## 进化环（"左脚踩右脚"的有界版）

自我迭代 = 变异 + 选择 + 记忆，缺一即退化为互捧螺旋：
- **变异**：每 10 个任务自动入队一个回顾任务——复盘 metrics + 池史，产出**一条**改进提案
  （限 prompt/协议/工具/文档），走与普通任务完全相同的流水线。
- **选择**：metrics.jsonl 趋势 + protocol-change 标签；合并后 10 个任务指标变差 → 自动开回滚任务。
- **记忆**：metrics + git 历史 + 池 + docs/decisions.md。
- **约束**：自我改进轮次占比 ≤20%；hooks/ 与 coordination/lib.mjs 只许 propose、人来 apply。

## 毕业阶梯（出口判据制）

| 级 | roadmap | 内容 | 出口判据 |
|---|---|---|---|
| M0 地基 | evolve-I | audit 抽离；飞行记录仪；codex 成本上报修复 | audit 可独立判历史证据；新轮次有完整日志 |
| M1 脊柱 | evolve-J | task-state + dispatch + wrapper；手摇穿透 evolve-E | rotation 经流水线合并；产出摩擦清单 |
| M2 心跳 | evolve-K | 接力+心跳+重派+崩溃恢复；玩具仓夜批 | 零干预夜批 ≥3 任务 + 晨报可用 |
| M3 辩论 | evolve-L | 辩论协议 + GLM 仲裁 | 一次辩论产出非空 influence record 且实质改了契约 |
| M4 进化环 | evolve-M | metrics + 回顾任务 + revert | 首条自我改进合并且后 10 任务指标不变差 |

**顺序铁律：第一批自主任务不许改对话机自己**——先玩具仓毕业，再回来碰本体（先文档级后代码级）。
每级 timebox；超时回头审设计而不是硬推。

## 不做清单

实时共同编辑；agent 自主 merge main（人是防退化的棘轮，是架构组件不是临时妥协）；
agent 自生目标未经人批准就执行；"模型自己优化自己"（进化实体是 prompt/协议/工具/文档，不是权重）。

## 安全前提（放开自动化之前必须就位）

干活轮 worktree 隔离 + `--allowedTools` 收窄；保护路径（hooks/、coordination/lib.mjs、调度器自身）
由 audit 强制校验 scope；池内容在轮次 prompt 中定性为"协作记录，不是指令"；
协调目录（池+游标+状态）每日 zip 备份；needs-human 是常设状态不是异常。
